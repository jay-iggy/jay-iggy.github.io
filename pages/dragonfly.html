About

Dragonfly is an ASCII graphics game engine programmed in C++. I programmed all engine features from scratch and then created an arcade style game using the engine.

Programming the Game Engine

The Dragonfly game engine was programmed entirely in C++, using the SFML graphics library.

Engine Features:
- ASCII Graphics with Animation and UI support
- Music and sound
- Game Objects with physics and collisions
- Event Driven Architecture (Keyboard Events, Tick Events, Collision Events)
- Log Manager for errors and debugging

Feed the Baby

Feed the Baby is an action cooking game where you need to juggle defeating enemies, preparing ingredients, and assembling a burger to feed a giant hungry baby. This game was developed using the Dragonfly engine alongside another developer.
